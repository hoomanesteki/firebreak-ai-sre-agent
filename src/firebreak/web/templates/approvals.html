Audit chain

Every decision, in order, each hashed onto the one before it. Changing or removing any record breaks every hash after it, which makes an edit detectable by anyone who reads the file. That is tamper evidence and not tamper proofing: somebody who can write the file can rewrite the chain from where they changed.

What this page cannot do

Approve or reject. The approval service is a separate process holding the only credentials that can change a feature flag or restart a container, and giving this page a button that called it would put the decision and the credential back in one place. That is the arrangement the whole design is built to avoid, and it is asserted by a test that walks the import graph rather than by this paragraph.
